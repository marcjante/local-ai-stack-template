Trabaja como agente de desarrollo de este repositorio.

Lee primero `AGENTS.md` y `.codex/TASKS.md`.
Inspecciona el estado actual antes de modificar.
No hagas push.
Si estás en main, crea/usa una rama de trabajo antes de editar.
Prioriza cambios pequeños y comprobables.
Ejecuta tests relacionados después de cada cambio.
Si algo falla, diagnostica y corrige antes de continuar.
Al final muestra:
1. qué problema encontraste;
2. qué cambiaste;
3. tests/comprobaciones ejecutados y resultado;
4. `git diff --stat`;
5. riesgos o trabajo pendiente.

Cuando el usuario dé una tarea explícita, esa tarea tiene prioridad sobre TASKS.md.
