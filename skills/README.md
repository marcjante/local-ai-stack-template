# Local AI Studio — Skills

Sistema modular de capacidades para Local AI Studio.

Las skills no se cargan todas simultáneamente.
Un Skill Router seleccionará únicamente las necesarias según la tarea.

## Categorías

- systematic_review
- scientific
- qualitative
- experimental
- open_science
- academic
- optional

## Principio

Core genérico → Skill Router → Skills → Plugins/Tools → Resultado trazable

Cada skill podrá definir:

- nombre
- versión
- descripción
- tareas compatibles
- instrucciones
- herramientas necesarias
- modelos recomendados
- fuentes
- restricciones
- trazabilidad
